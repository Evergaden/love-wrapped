# 恋爱Wrapped

写给你们的小册子：由一个人填写的小程序。打开就是书架——写过的册子一本一本摆着；点「新写一本」开始填写。答案存在本机缓存，并自动备份一份到微信云开发（仅本人可见）。

写下两个昵称、在一起的日子，以及一些愿意记得的小事。然后左右滑动，翻一本只印了一份的小册子。翻到愿意留下的那一页，可以把它画成图片存进相册，也可以整本转发给对方——**对方点开就能看到你写好的那一册**。每一册有自己的配色，改一本的颜色不影响别的。

> **关于名称口径**
> 界面统一使用全名「恋爱Wrapped」，全部文案只在一处定义：`utils/brand.js`。
> 注意个人主体上架时，后台注册的小程序名称和类目仍要按平台规则选择，
> 注册名与界面名保持同一口径最稳妥。

## 你会看到什么

填写页 11 项，其中 3 项必填：

1. 你的昵称、TA 的昵称、在一起的日子（必填）
2. 第一次约会的地方
3. 现在住的城市，和一起去过的地方——一个一个加成小气泡（最多八块），纪念册拼成一页，标出每块离现居地多远
4. 一起吃饭的频率（估「≈ N 顿」），和你们最爱吃的东西——数字页会写一行「永远 爱吃 …」
5. 吵架次数，以及谁先道歉（可整项留空）
6. 口头禅
7. 一件难忘的小事（结尾页会记下「写于」的日子和那天的第 N 天）
8. 异地还是同城；异地写两座城市，中间隔着多少公里自动算出来；同城选个见面频率（可整项留空）
9. 想对 TA 说的一句话

生成时册子自动存一份快照到云端（「历史记录」页随时翻看）；收到的礼物册也能一键收进自己的历史记录，和自己的册子区分标记。

外加一组「挑一套配色」：奶油（默认）、抹茶、晴蓝、雾紫四套主题。
主题影响整本纪念册、导出的图片和转发卡片封面，存在本机随时可换。

纪念册固定 6 页，顺序是在讲一件事，和问卷顺序不一样，每页有自己专属的排版：

1. 封面——两个名字并肩，天数压在胶囊里
2. 数字——一张张小卡排下来，末尾预告下一个整百天或周年；近期有节气或传统节日时（30 天内），会换成更有日子感的一行：「1 天后，就是你们的第 4 个立冬」。收录二十四节气（清明除外）、春节、元宵、端午、七夕、中秋、重阳、腊八、除夕、情人节和 520，全部本地推算不联网（`cloudfunctions/     shareBook / getSharedBook / reminderSend 三个云函数
utils/festivals.js`）
3. 起点——一张明信片，日期缩成右上角的邮戳
4. 去过的地方——一页拼图，一块一块歪着拼，最远的那块挂「最远」
5. 口头禅——那句话装在一只气泡里
6. 一件小事——一页手记，左侧一道色条，正文首行缩进
7. 结尾——整页居中的终章，像扉页的题字

填了「异地 / 同城」会在去过的地方后面多一张「旅程图」：异地是推算出来的公里数压在虚线上，同城是估出来的见面次数，下面都写着「0 公里，想见就能见到」这类温柔话；填了吵架次数或谁先道歉，会在口头禅后多一页（普通排版）。都留空就是 6 页。

没填的项会用安静的普通排版放一句占位的话，翻起来不缺页。屏幕和导出图用同一套排版，`utils/slides.js` 里写 `layout`，`pages/wrapped` 管屏幕，`utils/poster.js` 管图片，改排版两边都要跟上。

点「填入一组示例」会放上示例内容，含吵架、异地和几处地方，所以是 10 页。

纪念册页底部 dock 有一排配色圆点，翻着翻着也能直接换主题。

## 用微信开发者工具打开

1. 安装稳定版微信开发者工具：<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>
2. 打开工具，用手机微信扫码登录。
3. 选择「小程序」，不要选「小游戏」。
4. 点「+」或「导入」。
5. 目录选**这一层**：文件夹里能直接看到 `app.json`。不要选到它的上一级，也不要只选中 `pages`。
6. AppID：填你自己的小程序 AppID。`project.config.json` 里的 `appid` 也需要同步换成同一个。
7. 如果问云开发或云服务，选「不使用」。
8. 确定之后，左侧模拟器应出现「恋爱Wrapped」。

### 在模拟器里走一遍

1. 点「挑一套配色」里的任一套，整页颜色会立即跟着换。
2. 点「填入一组示例」。
3. 滑到下面，点「生成纪念册」。
4. 在纪念册上按住鼠标向左拖翻页。左下角有页码，第一页写着「向左滑」。
5. 点 dock 上的配色圆点，整本马上换色。
6. 点「导出」→「导出此页」。稍等，底部弹出预览，导出的图片用的就是当前配色。
7. 点「查看大图」「直接发送给朋友」，或「存到相册」（模拟器常失败，见「已知限制」）。
8. 点「导出」→「导出整本长图」，会把整本画成一张**连贯的长图**：一张卡从头贯到尾，弥散光顺着长条流下去，节与节之间一道居中的短线，落款只在末尾出现一次。
9. 点「分享给 TA」转发给好友。转发卡片封面是专门画的 5:4 信纸；**对方点开卡片，直接看到你写好的整册**——链接里只有一枚云端令牌，答案存在你的云开发环境里，对方凭令牌经云函数取回。

改答案：点左上角返回，改完再点「生成纪念册」。字是边写边存的。

## 隐私与用户信息

- 收集范围：只有你自己在填写页输入的昵称、日期和几件小事。
- 存储位置：本机缓存（答案 `loveWrapped.answers.v1`、主题 `loveWrapped.theme.v1`、周年提醒的意愿记录 `loveWrapped.reminder.v1`），云端微信云开发环境里另存三份：`books` 册子快照、`shares` 转发凭据与只读快照、`reminders` 提醒计划——都按微信身份隔离，仅本人可读写。
- 内容检测：点「生成纪念册」时，云函数 `contentCheck` 会把填写的自由文本拼成一段，送微信官方接口 `security.msgSecCheck` 检测一次。只在生成时测这一次，检测结果不存档，云端不会为检测多留一份你的文字（细节见下文「内容安全检测」）。
- 转发：点「分享」时，云端先生成一枚随机令牌（30 天有效），链接里只有令牌；对方点开后凭令牌经云函数取回答案，看到一份只读的礼物：可以翻看、换配色、收进自己的历史记录（带「收下的」标记，不动本机自己写的那份）、或直接去做一本。令牌不可猜测，集合权限「仅创建者可读写」，没收到分享的人无法构造出能打开的链接。
- 清除：填写页「清空重写」删除本机答案；「我的 → 历史记录」里可删除云端册子；周年提醒在「我的」页可随时取消，云端计划一起关停。

### 代码里的隐私适配

- `app.json` 已开启 `__usePrivacyCheck__`。
- `utils/privacy.js` 封装了 `wx.getPrivacySetting` 和 `wx.requirePrivacyAuthorize`，两个页面进页时都会查一次。
- 基础库低于 2.32.3 时这些接口不存在，按「无需授权」处理，功能照常可用。

### 内容安全检测（只在生成时一次）

点「生成纪念册」时，云函数 `contentCheck` 会把填写的自由文本（两个昵称、地点、口头禅、小故事、想说的话、爱吃的东西等）拼成一段，调微信官方 `security.msgSecCheck` v2 检测一次（云调用，免费、不消耗云开发资源额度）。等待时显示「报告生成中…」；如果没通过，会轻轻提示「先放一放，有几句话暂时写不进这册，换个说法再试试吧」，改完再点生成；接口限频 / 权限未生效 / 网络异常时放行，不误伤正常用户。

检测通过后，分享令牌在生成时就备好，之后分享、改卡片标题、换主题都**不再重复检测**。

部署：`cloudfunctions/contentCheck`，`config.json` 里已声明 `permissions.openapi: ["security.msgSecCheck"]`（不声明会报 604101）。开发者工具右键该目录 →「上传并部署：云端安装依赖」，或用云开发 MCP 部署；权限配置有约 10 分钟缓存。

已知边界（两个生成之后/不经过生成的边缘入口，审核若要全覆盖再补）：分享面板里手输的卡片标题（≤24 字）是生成后才输入的；填写页右上角直接转发（不点生成）也不经过检测。前者可改成预设标题选项或单独检测那 24 字，后者可改成只发不带内容的普通卡片。

### 上架前必须在后台填的《用户隐私保护指引》

微信公众平台 → 设置 → 服务内容声明 → **用户隐私保护指引**。
不填这里，小程序审核会被判定「未提供隐私政策」驳回。

建议勾选/填写的条目如下（这个项目只用得到前两项）：

| 信息类型 | 用途说明 | 当前版本 |
| --- | --- | --- |
| **用户填写的信息** | 你输入的昵称、日期与文字，用于生成纪念册图片；点「生成纪念册」时经微信官方内容安全接口（`security.msgSecCheck`）检测一次，只判断能否写入，检测结果不留存；在本机缓存的同时，通过微信云开发自动备份一份（数据存于微信云开发环境，按微信身份隔离，仅本人可读写）；转发纪念册时，接收方凭随机令牌经云函数读取一份只读快照 | 云开发 + 本机 |
| **相册（仅写入）权限** | 把生成的纪念册图片保存到系统相册 | 仅在你点击「存到相册」时使用 |
| 剪切板 | 不收集 | 不使用 |
| 位置 / 手机号 / 微信好友 / 身份证号 | 不收集 | 不使用 |

「存到相册」只请求**写入**权限，不读取你相册里已有的任何照片。

## 上架（个人主体）

下面这条路是**个人主体 + 工具类**，不需要公司。完整清单见 [`上架清单.md`](上架清单.md)。

要点先说在这里：

- 个人主体可以注册小程序、做小程序备案，但**类目选择很窄**。`恋爱 / 情感 / 婚恋交友` 在个人主体下**基本选不到**。
- 所以你这个项目上架时，类目要选能过的那一类，**页面里的功能文案也要跟着它改**：
  - 推荐：**工具 → 效率** 或 **工具 → 信息查询**，官方描述写「本地文字记录与图片生成工具」
  - 可选：**生活服务 → 记事本 / 便签**
- 下列内容在上架前已经全部删除，请不要又加回来：任何形式的广告解锁、去水印、会员付费、双人互动，以及「假装完成了某个任务才能导出」的按钮。
- 一个小程序只能改名 2 次（一年内），名称里**不要**出现「恋爱」「情侣」「婚恋」这类词，不然提交审核或者后续被投诉都很麻烦。

## 获得的评价（称号体系）

倒数第二页会按内容颁发称号，像游戏成就一样有等级：

- **S级 · 稀有称号**：天作之合（全甜无雷点）/ 灵魂伴侣（共同记忆多）/ 恋爱天花板（两年+少架）/ 神仙情侣（一年+吵架<3）
- **A级 · 优秀称号**：甜蜜超标 / 黏黏糊糊 / 仪式感达人 / 模范情侣
- **B级 · 真实可爱**：双城搭子 / 旅行搭子 / 饭搭子 / 形影搭子 / 和平搭子 / 合拍搭子 / 默契搭子

规则在 `utils/record.js` 的 `awardTitle`，想要自己的称号规则就从那里改。转发卡片上也会印上分享者起的标题（比如「一周年快乐」）。

## 手写字体（霞鹜文楷）

启动时自动加载手写体「霞鹜文楷」（SIL OFL 1.1，免费商用可嵌入），全应用与
导出的图片都会用它；加载完成前显示系统字体，失败也不影响功能。

字体用**子集版（约 1.8MB）**：由 fontTools 从原版（11.7MB）子集化而来，字符清单 =
项目全部固定文案 + GB2312 一级字 3755 个 + ASCII + 中英标点；用户写出的清单外
生僻字会自动落回系统字体，不影响阅读。重新生成的命令：

```
pip install fonttools brotli
# 1) 从 jsdelivr 下载原版 LXGWWenKaiLite-Regular.ttf
# 2) 生成字符清单：扫描仓库源码里的固定文案，并上 GB2312 一级字与标点
# 3) 子集化（本仓库的 utils/ 全部文案必须先扫进去，一个都不能少）
python -m fontTools.subset LXGWWenKaiLite-Regular.ttf --text-file=chars.txt \
  --output-file=LXGWWenKaiLite-Subset-Regular.ttf \
  --layout-features='*' --name-IDs='*' --no-hinting
```

加载链路（每台手机只下一次，之后全走本地）：

1. 本地有缓存（USER_DATA_PATH）→ 直接本地加载，零流量
2. 没有缓存 → 下载一次、落盘、用本地文件加载
3. 本地路径加载失败（个别基础库）→ 远程直载，并记住该设备不再尝试缓存

**真机字体走微信云通道，无需配置服务器域名**：`wx.cloud.downloadFile`
（fileID 直下）属于云开发调用，官方规则免 downloadFile 域名校验。
本项目已接入：子集字体已上传云存储，fileID 已填在 `utils/font.js` 顶部。

- jsdelivr CDN 仅作兜底（没备案，真机被域名校验拦下，只有开发工具里能用）。
- 可选加固：mp 后台把 `*.tcb.qcloud.la` 加进 downloadFile 合法域名——只在个别
  基础库不认本地字体路径、需要远程直载兜底的设备上有意义，不加也不影响多数设备。

额度账：子集 1.8MB × 每台手机一次（缓存生效后不再消耗）；一万个用户总共
约 18GB 一次性下行流量。云存储不缓存直连的话是 1.8MB × 每次冷启动，量级完全不同。

临时想在新编译的预览里看一眼字体：真机上点右上角「…」→ 开发调试 → 打开调试，
会跳过域名校验（jsdelivr 国内直连不稳，且那是 11.7MB 的原版，要等一会儿）。

## 数据存在哪里

- 本机：微信（或开发者工具）的本地缓存里，三个键名：答案 `loveWrapped.answers.v1`，主题 `loveWrapped.theme.v1`，周年提醒的意愿记录 `loveWrapped.reminder.v1`（「清空重写」只删答案，配色保留）。
- 云端：微信云开发环境的三个集合：`books`（每次「生成纪念册」自动存一册快照）、`shares`（转发用的令牌与只读快照）、`reminders`（周年提醒计划）；都按微信身份隔离，仅本人可读写。云环境没开通时一切照旧走本地，不影响使用。

清缓存的位置：开发者工具顶部「清缓存 → 清除数据缓存」。

## 周年提醒（订阅消息）

生成纪念册时会轻轻问一次：「下个周年纪念日前 7 天，想在微信里收到提醒吗？」——同一个周年只问一次，拒绝过也不再弹。询问用的是**自制弹层**而不是原生 `showModal`：`wx.requestSubscribeMessage` 必须由用户点击（TAP）同步发起，modal 的确认按钮不算页面手势，真机上弹不出「允许通知」的授权面板。开启后，`reminders` 集合里会存一条计划，云函数 `reminderSend` 每天上午 9 点检查，提前 7 天下发订阅消息。

「我的」页里有一张「周年提醒」卡：已开启时可以**取消**（本地关闸 + 云端计划同步 `enabled: false`，定时函数不再挑这条计划），已取消时可以**重新开启**（按钮点击直接拉起授权，不用重新生成一册）。

接上线要做四件事（本项目已全部接好，这里留档备查）：

**1. 申请模板（mp 后台）**

微信公众平台 → 功能 → **订阅消息** → 公共模板库 → 搜「日程提醒 / 纪念日 / 日程」，选一个**一次性订阅**模板。选的时候只看一件事：字段组合要对得上云函数里发的三个键。本项目已申请「纪念日提醒」模板（类目信息查询），实际字段：

| 代码里的键 | 模板字段类型 | 内容 | 限制 |
|---|---|---|---|
| `thing1` | thing（事物） | 纪念日名称，如「第 4 个纪念日」（从 years 派生；没存年数就发「你们的纪念日」） | ≤20 字符，代码已裁剪 |
| `time2` | time（时间） | 日期，如 `2027年5月20日` | **时间型**：官方要求「日期 + 时刻」；当前按产品要求只发日期，真机若报 47003，把 `timeFor` 改回「日期 + 09:00」即可（回退办法写在云函数注释里） |
| `thing3` | thing（事物） | 备注「还有一周就是你们的第N年，为TA准备个惊喜吧」 | ≤20 字符，云函数里写死；N 为一位数时全句 22 字，结尾会被自动截断 |

模板库里字段组合对不上（比如只有 `thing1`/`time2`）时，换一个三个键都有的模板，或者改 `cloudfunctions/reminderSend/index.js` 里 `data` 的键名去迁就模板——**别硬填**，字段名不匹配会报 `47003`。若模板库提示类目不符，选通用的「日程提醒」类；个人主体工具类目通常可用。申请后复制那串模板 ID。

**2. 填模板 ID（两处，必须同一个值）**

- `utils/cloud.js` 顶部 `const REMINDER_TMPL_ID` → 已填本项目申请的模板 ID（客户端拉授权面板用）
- 云函数 `reminderSend` 的环境变量 `REMINDER_TEMPLATE_ID` = 同一个模板 ID（云函数下发用，已配置）

两处现在都填着本项目申请的同一个模板 ID（客户端的写在前端，云函数的走环境变量、不写死在云函数代码里）；以后换模板，两处要一起改。

**3. 部署 `reminderSend` 并确认触发器**

开发者工具右键 `cloudfunctions/reminderSend` →「上传并部署：云端安装依赖」。`config.json` 里已经写好两样，随上传生效：

- `permissions.openapi: ["subscribeMessage.send"]`（云调用权限，不声明报 604101）
- `triggers`: `0 0 9 * * * *`（**7 段** cron，每天北京时间 09:00 跑一次）

在云开发控制台 → 云函数 → 触发器里确认有一条 timer；没生成就手动加，cron 必须是 7 段。环境变量改动后也要重新部署才生效。

**4. 让用户完成一次授权**

模板接好前已经问过、只记了意愿的用户，下次生成纪念册会**再问一次**（状态机已修）。点「好呀」→ 微信弹出「允许通知」面板 → 允许，`reminders` 集合里那条计划变成 `subscribed: true`。「我的」页可以随时取消或重新开启。

**验证是否真的能发**

- 云开发控制台 → 数据库 → `reminders`：看 `enabled` / `subscribed` / `anniversary`
- 手动测：把某条计划的 `anniversary` 改成「今天 + 7 天」的日期（YYYY-MM-DD），在云函数控制台点「测试」跑一次 `reminderSend`，返回里 `sent: 1` 且手机微信「服务通知」收到消息即通
- 看日志：每天 9 点执行后返回 `{ found, sent, failed }`
- 常见错误：`43101` = 用户没订阅或额度用完（代码会自动关掉这条计划）；`47003` = 模板字段不匹配（回第 1 步）；`REMINDER_TEMPLATE_ID 未配置` = 环境变量没填

**几个容易踩的点**

- 一次性订阅：**授权一次只能收一条**。发完写 `lastNotifiedFor`，同一个周年不再重复；下一个周年生成时会再问一次
- 定时触发器按北京时间（UTC+8）09:00；小程序在后台、用户没打开过也能收到服务通知
- 模板 ID 已接好：点「好呀」会直接拉起微信的「允许通知」授权面板，同意后计划标成 `subscribed: true`，到点真的会收到服务通知。万一以后把模板 ID 清空，代码会退回只记意愿、不下发的老样子（`onReminderAgree` 里的兜底分支还在）

## 颜色与主题

四套主题（奶油 / 抹茶 / 晴蓝 / 雾紫）的色板、弥散底几何全部定义在 `utils/themes.js`：

- **屏幕上的弥散底和卡口细线**：由 `themes.js` 算成内联 style 直接挂在节点上
  （填写页的 `ambientMesh` / `ambientLower` / `ambientFade`，纪念册每页的
  `meshStyle` / `hairStyle`）。这样做是因为开发者工具里 swiper 内容对样式表的
  多级选择器级联不稳定，内联样式在工具和真机上都确定生效。
- **屏幕上其余的主题色**（标题字色、胶囊、落款、dock、进度条等）写在
  `pages/wrapped/wrapped.wxss` 和 `pages/index/index.wxss` 的 `.theme-xxx` 规则里。
- **导出图片**：`utils/poster.js` 从 `themes.js` 直接取色。
- **弥散底几何**（每摊的位置、大小、透明度）只有一份：`themes.js` 的
  `MESH_GEO`，屏幕和画布共用，只是画布的 alpha 单独一列。

改颜色 = 改 `themes.js`，再同步对应 `.theme-xxx` 的文字色；不用再像以前那样三处对表。

## 已知限制

- 本机缓存被清除（换手机、删除小程序、清缓存）后，本机答案没了，但可以从「我的 → 历史记录」把云端册子载回填写页找回；云端没存过（云环境未开通）的就找不回了。
- 公里数是按内置城市坐标库（`utils/geo.js`）用直线推算的，全部带「≈」。库里收录了全部省会、常见城市、旅行地和常见国家；没收录的名字照常显示，只是不算距离。
- 开发者工具里「存到相册」经常失败。请用「预览」到手机上保存，或先点「查看大图」、长按保存。
- 整本是连贯的长图，按内容实际高度绘制。整本很长时为了不超过画布边长，会比单页稍模糊；单页导出是按屏幕清晰度画的。
- 分享卡片封面会印两个昵称和「写于」当天的日期戳；答案也随卡片一起送达，对方点开直接看到整册。朋友圈转发不带答案（链接长度受限），点开仍是空白填写页。
- 天数按「开始当天为第 1 天」计算，同一份示例过几天再打开，封面天数会变。
- 分享需要云开发环境可用：令牌创建失败时（云不可用），分享退回一张普通卡片，不带内容。分享链接 30 天有效，过期后对方打开会看到「分享已过期」。
- 不做登录、广场、支付、地图、星座，也没有双人互相答题。
- 个人主体可以发布上线，但个人主体的可用类目受限，付费与广告能力也需要满足额外条件。

## 常见问题

**导入后提示找不到 app.json。**  
目录选高了一层。重新导入，选中能直接看到 `app.json` 的文件夹。

**模拟器一片空白，调试器有红字。**  
把调试基础库调到 3.x，再编译。确认导入类型是小程序，不是小游戏。

**点了生成，却说还差必填项。**  
两个昵称和日期都要有。昵称如果只有空格，也会被当成没填。

**示例是 10 页，我只想要 6 页。**  
回到填写页，吵架选「先不写」并清空次数，距离选「先不写」，把一起去过的地方一块块点 × 删掉，再生成。底部会写「会生成 6 页」。

**导出图片是空白的。**  
先把基础库调到 3.0 以上。仍空白的话，用手机预览再试一次。

**改了句子但纪念册没变。**  
改的是 `utils/slides.js` 的话，保存文件后点「编译」。改的是填写内容的话，返回填写页再点一次「生成纪念册」。

**想用得意黑字体。**  
项目默认用手机自带字体（苹方、黑体、微软雅黑）。得意黑完整文件有几 MB，超过小程序主包上限，所以不放进项目。如果确实要用，需要自备 HTTPS 字体地址，在 `app.js` 里用 `wx.loadFontFace` 加载；正式版还需要把该域名配到小程序后台的 `downloadFile` 合法域名里，并且这个域名要你自己备案。不做这一步并不影响任何功能。
