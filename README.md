# 恋爱Wrapped

一个人填写、在微信开发者工具里就能看的纪念册小程序。没有后端，答案只留在这台设备上。

你写下两个昵称、在一起的日子，以及一些愿意记得的小事。然后左右滑动，翻一本只印了一份的小册子。可以把它画成图片；图片上默认有「演示水印」。底部那一行可以**假装**看完一条激励视频，之后再导出就没有水印。这里没有真的广告。

## 你会看到什么

填写页大约 11 项：

1. 你的昵称、TA 的昵称、在一起的日子（这三项必填）
2. 第一次约会的地方
3. 一起去过几座城市
4. 一起吃过多少顿饭
5. 吵架次数，以及谁先道歉（可以整项留空）
6. 口头禅
7. 一件难忘的小事
8. 异地还是同城；异地填公里，同城填一起出门的次数（可以整项留空）
9. 想对 TA 说的一句话

纪念册固定 6 页，顺序是在讲一件事，和问卷的顺序不一样：

1. 封面
2. 数字
3. 起点
4. 口头禅（深玫瑰色）
5. 一件小事
6. 结尾

填了「异地 / 同城」会在起点后面多一页。填了吵架次数或谁先道歉，会在口头禅后面多一页。都留空就是 6 页。

点「填入一组示例」会放上虚构的「小熊」和「阿树」，含吵架和异地，所以是 8 页。

## 用微信开发者工具打开

不需要会写代码，也不需要申请正式小程序。

1. 安装稳定版微信开发者工具：<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>
2. 打开工具，用手机微信扫码登录。
3. 选择「小程序」，不要选「小游戏」。
4. 点「+」或「导入」。
5. 目录选**这一层**：文件夹里能直接看到 `app.json`。不要选到它的上一级，也不要只选中 `pages`。
6. AppID：点「测试号」。没有测试号就选游客模式。`project.config.json` 里写的是 `touristappid`，工具如果提示不合法，让它自己填测试号即可。它可能会改写这个文件，不用改回来。
7. 如果问云开发或云服务，选「不使用」。
8. 确定之后，左侧模拟器应出现标题「恋爱Wrapped」。
9. 如果模拟器是白的：右上角「详情 → 本地设置」，把调试基础库调到 **3.0 或更高**（项目建议 3.5.5），再点「编译」。

### 在模拟器里走一遍

1. 点「填入一组示例」。
2. 滑到下面，点「生成纪念册」。
3. 在纪念册上按住鼠标向左拖，翻页。左下角有页码，第一页写着「向左滑」。
4. 口头禅那一页是深玫瑰色，字是白色的。
5. 点「导出此页」。稍等，底部会弹出一张图，图上有淡淡的「演示水印」。
6. 点「关闭」。再点底部「点此模拟激励视频」。
7. 弹窗标题是「激励视频（演示）」。点「看完了」。不会出现广告。
8. 再点「导出此页」。新图上不再写「演示水印」。
9. 「导出整本」会把每一页画成一张长图。
10. 「存到相册」在电脑模拟器里经常失败。这是工具的限制。要真正存进手机，用工具栏的「预览」，用微信扫码，允许相册权限后再存。手机上也可以长按预览图保存。

改答案：点左上角返回，改完再点「生成纪念册」。字是边写边存的，关掉工具再打开，填写页里还在。

看空白纪念册：如果还没填必填项就打开了结果页，会看到「这本纪念册还是空白的」，可以去填写，或「用示例看一看」。

## 数据存在哪里

存在微信（或开发者工具）的本地缓存里，键名是 `loveWrapped.answers.v1`。

不会上传，没有账号，也没有云数据库。分享给朋友时，对方打开的是空白填写页，看不到你的答案。

清缓存的位置：开发者工具顶部「清缓存 → 清除数据缓存」。清掉之后答案和「已模拟去水印」的标记都会消失。

## 这个项目里的文件

```
app.js              小程序入口。字体加载的例子在这里，默认不执行
app.json            有哪些页面、窗口颜色
app.wxss            全局底色和按钮
sitemap.json        微信要求的索引配置
project.config.json 开发者工具的项目配置
pages/index         填写页
pages/wrapped       滑动纪念册和导出
utils/record.js     答案有哪些字段、日期怎么算
utils/sample.js     示例「小熊 / 阿树」
utils/slides.js     答案怎么变成每一页的句子
utils/storage.js    读写本机缓存
utils/poster.js     用画布把一页画成图片
```

想改纪念册上的句子，打开 `utils/slides.js`。想改示例，打开 `utils/sample.js`。

颜色有三处，要一起改，导出的图片才会和屏幕一样：

| 用途 | 色值 |
| --- | --- |
| 奶油底 | `#FFF5F7` |
| 粉 | `#FF8FAB`、`#FFC2D1` |
| 字 | `#2D1B24` |
| 口头禅页 | `#E85A7A`，字是白色 |

屏幕上的颜色在 `app.wxss` 和 `pages/wrapped/wrapped.wxss`。图片上的颜色在 `utils/poster.js` 开头的 `THEMES`。

每一页的装饰形状最多两个（一个圆、一块圆角矩形这类）。不要再往某一页上加第三块色块。

## 放到 GitHub

下面假设你的 GitHub 用户名是 **Evergaden**。仓库名可以用 `love-wrapped`，也可以换成别的。两种办法选一种。

### 办法一：用网页上传（不用安装 Git）

1. 用浏览器打开 <https://github.com/new> ，登录 Evergaden。
2. Repository name 填 `love-wrapped`。
3. 选 Public。
4. **不要**勾选 “Add a README”、“Add .gitignore” 或 license。这些文件项目里已经有了，勾上之后再上传容易冲突。
5. 点 Create repository。
6. 在空仓库页面找到 **uploading an existing file**（或 Add file → Upload files）。
7. 把下面这些拖进页面：
   - `app.js`、`app.json`、`app.wxss`
   - `sitemap.json`、`project.config.json`
   - `README.md`、`.gitignore`
   - 整个 `pages` 文件夹
   - 整个 `utils` 文件夹
8. 不要上传 `.git` 文件夹。不要上传 `project.private.config.json`（开发者工具自动生成的个人设置，已经写在 `.gitignore` 里）。
9. 下面的说明写成：`恋爱Wrapped 初版`
10. 点 Commit changes。

上传完成后，地址会像这样：`https://github.com/Evergaden/love-wrapped`

Chrome 可以直接把文件夹拖进上传页。如果网页把整个 zip 当成一个文件，请不要只传 zip，要传解开后的文件和文件夹。

### 办法二：用 Git 命令推送

1. 安装 Git：<https://git-scm.com/downloads>
2. 第一次在这台电脑上使用时，在终端执行（邮箱换成你 GitHub 账号用的邮箱）：

```bash
git config --global user.name "Evergaden"
git config --global user.email "你的邮箱"
```

3. 进入项目文件夹（里面能看到 `app.json` 的那一层），执行：

```bash
git init
git add .
git commit -m "恋爱Wrapped 初版"
git branch -M main
git remote add origin https://github.com/Evergaden/love-wrapped.git
git push -u origin main
```

4. 让你输入密码时，**不是** GitHub 登录密码。需要一只 Personal Access Token：
   - 打开 <https://github.com/settings/tokens>
   - Generate new token (classic)
   - 勾选 `repo`
   - 生成后复制那一串字符，贴到密码框

如果这台电脑上的文件夹已经有 `.git`（例如你是从别的地方克隆下来的），不要再执行 `git init`。远程如果已经存在，就不要重复 `git remote add`。不确定的话，用办法一更不容易弄乱。

## 想用得意黑

标题现在用的是手机自带字体（苹方、黑体、微软雅黑）。样式里已经把 `"Smiley Sans"` 放在字体名单的第一位。字体加载成功后，标题会自动换成它。

得意黑是开源字体，仓库在 <https://github.com/atelier-anchor/smiley-sans> 。完整文件有几 MB。小程序主包大约只能有 2MB，所以这里**不把字体文件放进项目**，否则开发者工具预览或上传时会报体积超限。

如果你有一个自己的 https 字体地址：

1. 打开 `app.js`。
2. 把 `loadSmileySans` 里的 `https://example.com/SmileySans-Oblique.ttf` 换成你的地址。建议用 ttf 或 woff。woff2 在旧基础库上可能不行。
3. 删掉 `onLaunch` 里 `this.loadSmileySans()` 前面的注释斜杠。
4. 开发者工具「详情 → 本地设置」勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。
5. 重新编译。调试器里看到「得意黑已加载」就成功了。失败的话，界面仍用系统字体，不影响填写和翻页。

真机正式版还要把该域名配到小程序后台的 downloadFile 合法域名里。测试号做不到这一步，所以演示阶段用系统字体即可。

## 已知限制

- 没有服务器。换手机、删除小程序、清除缓存，答案都没了，也不能从云端找回。
- 「激励视频」是假的，按钮和弹窗都写了「演示」。不会播放广告，没有收益，也不会跳到支付。
- 去水印只影响之后导出的图片，存在本机标记 `loveWrapped.unlockMock.v1`。可以点同一行字恢复水印。
- 开发者工具里「存到相册」经常失败。请用「预览」到手机上保存，或先点「查看大图」。
- 整本长图为了不超过画布边长，会比单页稍模糊。单页导出是按屏幕清晰度画的。
- 分享卡片不带昵称。朋友点进来是一张空白填写页。
- 天数按「开始当天为第 1 天」计算，所以同一份示例，过几天再打开，封面上的天数会变。
- 不做登录、广场、支付、地图、星座，也没有双人互相答题。
- 测试号 / 游客模式不能发布上线。要给不在身边的人用，需要注册小程序并用手机预览。

## 常见问题

**导入后提示找不到 app.json。**  
目录选高了一层。重新导入，选中能直接看到 `app.json` 的文件夹。

**模拟器一片空白，调试器有红字。**  
把调试基础库调到 3.x，再编译。确认导入类型是小程序，不是小游戏。

**点了生成，却说还差必填项。**  
两个昵称和日期都要有。昵称如果只有空格，也会被当成没填。

**示例是 8 页，我只想要 6 页。**  
回到填写页，吵架选「先不写」并清空次数，距离也选「先不写」，再生成。底部会写「会生成 6 页」。

**导出图片是空白的。**  
先把基础库调到 3.0 以上。仍空白的话，用手机预览再试一次。

**改了句子但纪念册没变。**  
改的是 `utils/slides.js` 的话，保存文件后点开发者工具的「编译」。改的是填写内容的话，返回填写页再点一次「生成纪念册」。
